# Smoke-тесты VASSKASS • FLOW

```
node tests/smoke.js              # весь набор, ~50 с
node tests/smoke.js --only=анкета  # только сценарии, в имени которых есть подстрока
node tests/smoke.js --verbose    # плюс шаги анкеты и значения формы плана
node tests/smoke.js --headed     # с окном браузера
```

Нужен только глобально установленный `playwright` с Chromium; `npm install` не нужен.
Скрипт сам поднимает статический сервер из корня репозитория на свободном порту.
Supabase и внешние CDN мокаются (ответ 200, `[]` или пустое тело); service worker отключён.

Код выхода 0, если всё прошло, и 1 при любом FAIL или если прогон дольше 150 с.
Для каждого сценария печатается `PASS`, `FAIL` с причиной или `SKIP`.

Сценарии: загрузка без pageerror и 404; регистрация; гостевой режим (если есть кнопка
«Начать без регистрации»); анкета по веткам (женщина и похудение, мужчина и набор с «Пропустить»,
беременность из вопроса о здоровье, подросток) с проверкой нумерации «Вопрос N из M» и норм калорий;
еда (форма, quickAdd/#qa90, удаление); вода; вес с запятой; XSS в названии еды; перезагрузка,
выход и вход; вкладки и горизонтальная прокрутка на 320 и 375 px; все оформления `MODES_ALL`.
